# RShiny Result Browser

The Shiny app reads benchmark outputs from `results/` and provides a searchable result browser.

Public app: https://caffeinated-code.shinyapps.io/PerturbSeq_Benchmarking/

Run from the repository root:

```bash
Rscript -e "shiny::runApp('shiny', host = '127.0.0.1', port = 3850)"
```
